# S2J Content Dates

公開日と更新日を、コンテンツタイプごとに表示する WordPress プラグインです。判断の正は [S2J Content Dates Service](https://github.com/stein2nd/s2j-content-dates-service) にあります。

確定前の仕様は [docs_mod/specs.md](docs_mod/specs.md) です。

実行環境は PHP v8.3以降です (WordPress [必須要件](https://ja.wordpress.org/about/requirements/)に合わせる)。
